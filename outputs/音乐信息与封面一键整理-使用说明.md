# 音乐信息与专辑封面一键整理

## 使用方法

1. 双击 `音乐信息与封面一键整理.exe`，无需安装 Python。
2. 程序启动后会自动扫描上次使用的文件夹；首次运行时扫描 EXE 所在文件夹。也可以点击“选择文件夹…”切换目录，或点击“追加音乐…”一次加入多首音乐。新扫描到或新追加的音乐默认不勾选；重新扫描时，只保留仍在扫描范围内的原有勾选，新出现的音乐保持未勾选。
3. 每首曲目前都有独立复选框。可逐曲勾选，也可使用“全选”“全不选”和“反选”；“包含子文件夹”控制是否递归扫描。
4. 本地扫描完成后，表格会立即显示当前标题、艺术家、唱片集、年份、日期、信息完整状态和封面状态。点击一行可在右侧查看封面预览与完整信息；两者位于同一详情框内，可使用滚轮一起滚动。
5. “勾选信息不完整”和“勾选缺失封面”可直接筛出相应曲目。如果筛选会排除原已勾选曲目，程序会询问是否保留：选择“是”合并原勾选，选择“否”只保留筛选结果，选择“取消”不作改变。
6. 点击“① 联网核对勾选项”。程序会逐曲核对唱片集资料和正式封面；正式封面找不到时，再尝试查找歌手照片并明确标成“待二次确认”。此时不会修改音乐。
7. 如预览显示歌手照片，可在右侧使用“换一张歌手照片”浏览已通过匹配和图片校验的其他候选；界面会显示当前是第几张，最终写入当前停留的照片。
8. 确认后点击“② 写入勾选项”。如存在歌手照片候选，程序会再次询问是否把它们写作封面；选择“否”仍可继续写入曲目信息，但封面保持空白，选择“取消”则终止本次写入。底部会实时显示当前阶段、当前歌曲、进度条和 `完成数/总数`。
9. “清理日志与缓存”会在确认后删除历史执行记录和已下载的封面缓存，但保留设置、上次文件夹和所有歌曲勾选状态。
10. 点击“使用说明”可随时打开内置的可滚动说明窗口；无需保留本说明文件。

## 整理范围

- 只补充或纠正：标题、艺术家、唱片集、唱片集艺术家、发行年份、发行日期。
- 唱片集艺术家统一写成与参与创作的艺术家相同。
- 已有封面默认保留。
- 缺少封面时，只采用经过唱片集名称、艺术家和发行信息核对的正式封面。
- 找不到可靠正式封面时，可采用与公开音乐目录主歌手名或 Wikipedia 人物页标题严格匹配的歌手照片。程序会合并相同画面的不同尺寸和裁切；有多张不同照片时可在右侧切换，最终采用当前显示的一张，但必须在写入前经过二次确认。
- 找不到可靠的正式封面或歌手照片，或者二次确认选择不采用时，封面保持空白；程序不生成、猜测或强行套用图片。

## 文件格式

- 可写入：FLAC、MP3、AAC、M4A、MP4。
- WMA/ASF 可以识别，但为避免兼容性风险，工具不会自动写入其封面。

## 安全与记录

- 每首音乐先复制为同目录临时文件，在临时文件中写入并复读验证；验证成功后才原子替换原文件。
- 程序首次运行后，会在 EXE 旁创建 `音乐整理工具数据` 文件夹，用来保存设置、封面缓存、执行预览、写入结果、独立复查和回滚记录。
- 下次启动会恢复上次文件夹、递归选项、自动联网选项、窗口大小、日志显示状态和每首歌曲的勾选状态。
- EXE 不依赖固定安装路径。移动工具时，将 EXE 和同级的 `音乐整理工具数据` 文件夹一起移动即可保留设置与缓存；目标位置需要具备普通文件写入权限。由于上次文件夹保存的是绝对路径，原音乐目录仍存在时会继续扫描原目录，也可在界面中重新选择。
- 联网核对需要网络连接；目录服务暂时限流时会自动切换其他来源。
