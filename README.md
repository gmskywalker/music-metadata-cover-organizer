# 音乐信息与专辑封面一键整理

一个面向 Windows 本地音乐库的图形化整理工具，用于核对并安全补充音乐标签和封面。当前版本为 2.9。

## 功能

- 扫描文件夹或一次选择多首音乐，逐曲复选处理。
- 显示标题、艺术家、唱片集、年份、日期、信息完整状态和封面状态。
- 联网核对标题、艺术家、唱片集、唱片集艺术家、发行年份和发行日期。
- 优先查找正式唱片封面；找不到时可提供严格匹配的歌手照片候选。
- 多张歌手照片可在右侧预览并切换；写入前的二次确认弹窗也会显示当前照片，并提供“上一张”“下一张”。
- 找不到可靠图片时保持空白，不生成或猜测封面。
- 写入临时副本并复读验证成功后，才原子替换原音乐。
- 实时显示当前阶段、当前曲目和完成进度。
- 记住上次目录、窗口状态、选项和曲目勾选状态。

## Portable 版本

直接运行 [portable/AAA音乐信息与封面一键整理.exe](portable/AAA音乐信息与封面一键整理.exe)，无需安装 Python。

EXE 特意保留 `AAA` 文件名前缀。实际使用时，工具通常和音乐放在同一个文件夹；Windows 按名称排序后，`AAA` 会让工具稳定排在歌曲文件前面，避免它夹在数百首音乐中难以寻找。这个前缀只影响文件排序，不是版本号，也不影响程序功能。

首次运行会在 EXE 同级创建 `音乐整理工具数据`，保存设置、封面缓存和执行记录。该目录包含本机状态，已被 Git 忽略，不应提交到仓库。移动 portable 版本时，把 EXE 和已有的 `音乐整理工具数据` 一起移动即可保留设置。

## 使用流程

1. 选择音乐文件夹，或追加多个音乐文件。
2. 勾选需要处理的曲目，也可一键勾选信息不完整或缺少封面的曲目。
3. 点击“① 联网核对勾选项”生成只读预览。
4. 在右侧检查拟写入的信息和图片；歌手照片有多个候选时可点击“换一张歌手照片”。
5. 点击“② 写入勾选项”。使用歌手照片时会弹出带照片预览的二次确认；可用“上一张”“下一张”切换，底部仍通过“是”“否”“取消”作决定。

拒绝歌手照片不会阻止补充曲目信息；选择取消则终止本次写入。

## 支持格式

- 可安全写入：FLAC、MP3、AAC、M4A、MP4。
- WMA/ASF 可以读取；为避免兼容性风险，不自动写入其封面。

## 从源码运行

需要 Windows、Python 3.12 和网络连接。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe ".\outputs\音乐信息与封面一键整理.py"
```

源码模式下，程序会从 `work/reviewed_cover_seed.json` 读取已复核的音乐目录种子。

## 构建 EXE

```powershell
.\build.ps1
```

构建结果会覆盖 `portable/AAA音乐信息与封面一键整理.exe`。构建依赖固定在 `requirements-build.txt`。

## 隐私与仓库范围

本仓库只保存程序源码、构建配置、已复核目录种子和 portable 成品，不包含音乐文件、本机设置、执行日志、封面缓存或个人标签备份。
